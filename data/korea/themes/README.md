# 한국사 지도 화면 데이터 형식

`pipeline/build_korea_map.py` 가 아래 파일을 모아서 `web/data/korea_map.json` 을 만들어요.

| 파일 | 내용 |
|---|---|
| `data/korea/themes/*.yaml` | 교과서 지도 (주제도) |
| `data/korea/admin/points.yaml` | 시대별 지방 행정 중심지 (9주 5소경, 5도 양계, 8도 감영) |
| `data/korea/institutions.yaml` | 통치 체제 그림 (중앙 정치 조직·지방·군사) |
| `data/korea/terms.yaml` | 교과서 용어 사전 (찾아보기에 있는데 사건·나라·왕·전쟁 이름으로는 찾을 수 없는 용어) |
| `data/korea/hanyang.yaml` | 한양 도성 지도 |
| `data/korea/faction_map.yaml` | 붕당 지도 (지역 기반·서원·한양의 집) |

공통 원칙
- 설명(d, s)은 해요체 1~3문장이고, 교과서 문장을 그대로 옮기지 않고 자기 말로 써요.
- 교과서와 맞지 않거나 확실하지 않은 내용은 넣지 않고 `note` 에 적어요. 교과서에 없는 심화 내용은 `deep: 1` 을 붙이고 출처(`web`)를 달아요.
- 좌표는 `[경도, 위도]`. 위치가 대략적이면 `ap: 1`.
- 연도는 정수(기원전은 음수). 1895년까지의 날짜는 음력이에요.
- 쪽수: `pg` 는 비상 교과서 쪽, `mp` 는 미래엔 교과서 쪽이에요.
- 독도는 우리 영토이고, 바다 이름은 동해로 써요.

## 1. 교과서 지도 (themes/*.yaml)

교과서에 실린 지도 하나를 주제 하나로 옮겨요. 파일은 시대별로 나누고, 한 파일에 YAML 목록으로 여러 주제를 적어요.

| 키 | 뜻 |
|---|---|
| id | 영문 소문자-하이픈, 전체에서 유일 |
| n | 지도 이름 (교과서 그림 제목에 가깝게) |
| era | 시대 이름 (선사·고조선, 여러 나라, 삼국, 남북국, 고려, 조선 전기, 조선 후기, 근대, 일제 강점기, 현대) |
| f, t | 이 지도가 다루는 기간 (연도, 기원전은 음수) |
| y | 지도를 열 때 맞출 연도 (없으면 t) |
| steps | true 면 '단계별로 보기' 단추로 항목의 y 순서대로 연도를 넘겨요 |
| view | 처음 보여 줄 범위: `korea`(한반도) · `manchuria`(만주까지) · `eastasia`(동아시아) · `[서경, 남위, 동경, 북위]` |
| admin | 도별 색칠(regions)에 쓸 행정 구역: `joseon8` · `daehan13` |
| src | 근거: `[{b: 비상, p: 145, fig: "❷ 대동법의 확대 과정"}, {b: 미래엔, p: 139, fig: ...}]` |
| d | 설명 (해요체 2~3문장, 교과서 내용과 맞게) |
| legend | 범례 `[{k: 종류키, n: 이름, c: '#색'(선택)}]` — 항목의 k 와 이어져요 |
| regions | 도 색칠 `[{id: 경기도, k, y, lab}]` (admin 의 도 이름: 경기도·충청도·전라도·경상도·강원도·황해도·평안도·함경도·제주·울릉도) |
| points | 점 `[{n, at: [경도, 위도], k, y, t, s, ap}]` |
| lines | 선 `[{n, k, path: [[경도, 위도, "지명"(선택)], ...], arrow: true, y, t, s, ap}]` |
| areas | 손으로 그린 구역 `[{n, k, poly: [[경도, 위도], ...], y, t, s, ap}]` |
| labels | 글자만 `[{n, at, k}]` (나라 이름, 바다 이름 등) |
| notes | 화면 아래에 덧붙일 말 (대략적인 부분, 교과서끼리 다른 점) |

- 항목의 `y`(나타나는 해)·`t`(사라지는 해)가 없으면 늘 보여요. 연도를 움직이면 그해까지 나타난 것만 보여요.
- `s` 는 항목을 눌렀을 때 나오는 한 줄 설명이에요.
- 모르는 곳은 지어내지 말고 빼거나 `ap: 1` 과 함께 근처 큰 고을 위치를 써요.

## 2. 통치 체제 (institutions.yaml)

교과서의 '중앙 정치 조직' 같은 그림을 상자 그림으로 보여 줘요.

```yaml
- id: joseon-central            # 영문 id
  n: 조선의 중앙 정치 조직
  era: 조선 전기
  f: 1392                       # 이 체제가 쓰인 기간
  t: 1894
  src: [{b: 비상, p: 118, fig: "❶ 조선의 중앙 정치 조직"}, {b: 미래엔, p: 110}]
  d: 2~3문장 설명
  nodes:                        # 위에서 아래로. p 는 윗 상자의 id
    - {id: king, n: 왕}
    - {id: uijeongbu, n: 의정부, p: king, s: 최고 정무 기구 … }
    - {id: yukjo, n: 6조, p: uijeongbu, s: …, kids: [이조, 호조, 예조, 병조, 형조, 공조]}
    - {id: samsa, n: 3사, p: king, s: …, kids: [{n: 사헌부, s: …}, {n: 사간원, s: …}, {n: 홍문관, s: …}]}
  notes: [교과서끼리 다른 점 등]
```

- `kids` 는 상자 안의 작은 칸이에요(문자열 또는 `{n, s}`).
- `t1: 1` 을 붙인 상자는 교과서 그림에서 강조된 것(예: 3사)이에요.

## 3. 용어 사전 (terms.yaml)

```yaml
- n: 골품제                     # 교과서 표기 (비상 우선)
  a: [골품 제도]                # 다른 이름·미래엔 표기 (선택)
  k: 제도                       # 제도 · 사회 · 경제 · 문화유산 · 유적·유물 · 책·기록 · 예술 · 사상·종교 · 인물 · 사건 · 장소 · 개념
  era: 삼국
  y: 520                        # 대표 연도 (선택)
  f: 0                          # 기간 (선택)
  t: 0
  d: 해요체 1~3문장
  pg: [37]
  mp: [30]
  at: [129.33, 35.79]           # 지도에 찍을 곳 (문화유산·유적·장소일 때만)
  ev: [event-id]                # 관련 사건 id
  inst: silla-central           # 관련 통치 체제 id
  note: 확인 메모 (화면에 안 나와요)
```

## 4. 한양 도성 (hanyang.yaml)

```yaml
name: 한양 도성
src: [{b: 비상, p: 114, fig: …}, {b: 미래엔, p: 106, fig: …}]
d: 설명
view: [126.94, 37.535, 127.03, 37.605]    # 처음 보여 줄 범위
walls:                                     # 도성 성곽 (대략)
  - {n: 한양 도성, f: 1396, ap: 1, s: …, path: [[경도, 위도, "지명"], …]}
waters:                                    # 한강·청계천 (선)
  - {n: 청계천, path: […], ap: 1}
hills:                                     # 내사산 (점)
  - {n: 북악산, at: […]}
places:
  - id: gyeongbokgung
    n: 경복궁
    k: 궁궐                                # 궁궐 · 성문 · 제사 · 관청 · 교육 · 시장 · 사건 장소 · 근대 시설 · 일제 시설 · 기념물
    at: [126.977, 37.5796]
    f: 1395                                # 생긴 해 (없으면 처음부터)
    t: 0                                   # 없어진 해 (선택)
    st: [{f: 1592, t: 1864, n: 불탄 터, s: …}]   # 이 기간에는 모습이 달라요(불탐·바뀐 이름 등)
    s: 한 줄 설명
    ev: [event-id]                         # 이곳에서 일어난 사건
    pg: [114]
    mp: [106]
    deep: 1                                # 교과서에 없는 심화 내용
    web: [출처 URL]
```

## 5. 붕당 지도 (faction_map.yaml)

세력 id 는 `data/korea/factions.yaml` 의 id(dongin, seoin, namin, bugin, noron, soron, …)를 써요. 집권 기간·환국은 factions.yaml 의 rule·marks 를 그대로 써요.

```yaml
regions:                 # 학문·지역 기반 (도 단위 색칠, admin: joseon8 의 도 이름)
  - {fac: dongin, do: [경상도], f: 1575, s: …, pg: [126]}
schools:                 # 학통의 중심이 된 학자·서원 (전국 지도 위 점)
  - {n: 도산 서원, fac: namin, who: 이황, at: […], f: 1574, k: 서원, s: …, pg: […]}
houses:                  # 한양 안의 장소 (동인·서인 이름의 유래 등)
  - {n: 김효원의 집 (건천동), fac: dongin, at: […], ap: 1, f: 1575, s: …, deep: 1, web: […]}
places:                  # 그 밖의 붕당 관련 장소 (회덕·이산, 탕평비 등)
  - {n: …, fac: …, at: […], y: …, s: …}
turns:                   # 전환점 카드 (factions.yaml 의 marks 와 이어짐)
  - {y: 1680, n: 경신환국, out: [namin], in: [seoin], s: …, ev: [event-id], pg: […]}
```
