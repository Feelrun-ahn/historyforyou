# 한국사 사건 데이터 (지도의 '사건' 표시와 연표 목록)

기준: 2015 개정 중학교 역사② (비상교육, 이병인 외 2020) 본문·부록 연표 + 한국민족문화대백과사전·우리역사넷으로 확인.
파일은 시대별로 나눠 두었고 `pipeline/build_events.py` 가 모아서 `web/data/events.json` 을 만들어요.

## 필드
| 키 | 뜻 |
|---|---|
| id | 영문 소문자-하이픈, 전체에서 유일 |
| n | 사건 이름 (교과서 용어) |
| d | 날짜. `1446`, `'1446-09'`, `'1446-09-29'` (기원전은 `-2333`). 1895년까지 한국 사건은 **음력** |
| ds | 양력으로만 아는 날짜 (1895년 이전이면 빌드할 때 음력으로 바꿔 d 를 채워요) |
| e | 끝 날짜 (기간 사건) |
| dt | 날짜 표시 문구를 직접 지정 (예: `기원전 4세기경`) — 이때 d 는 정렬·지도용 대략값 |
| c | 분류: 정치·외교·전쟁·사회·경제·문화·민족운동·민주화·통일 |
| i | 중요도 3=교과서 핵심(연표), 2=본문, 1=보조 |
| at | [경도, 위도] |
| ap | 1 이면 위치가 대략적 (도읍 좌표로 대신했거나 학설이 갈림) |
| p | 장소 이름 |
| pg | 교과서 쪽수 (확인한 곳) |
| t | 설명 (해요체 1~2문장) |
| nomap | 1 이면 지도에는 안 그리고 연표 목록에만 |
