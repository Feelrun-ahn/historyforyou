# history-map (가칭)

전 세계 나라들의 국경과 전쟁을 시간 순서대로 보여주는 인터랙티브 역사 지도.
연도 슬라이더를 움직이면 국경이 바뀌고, 나라나 전쟁을 누르면 설명이 나와요.

> 지금 상태: **12단계(태블릿 화면 정리·자세한 설명)까지 완료** — 모든 사건·한국사 전쟁·용어에 자세한 설명, 사건 527개, 한국사 전쟁 44개(전투 178개·진격로 105개), 국제 관계 98개, 세력 흐름 5개 시대, 왕·지도자 212명, 한반도 강 15개, 교과서 지도 44개, 통치 체제 그림 19개, 용어 사전 364개, 한양 도성 장소 31곳

## 연도 고르기

- **큰 막대**: 5,400년을 한 줄에 담아서 시대를 빠르게 고를 때 써요. 색 표시는 전쟁이 있었던 때(빨강 한국사, 남색 세계사)이고, 손으로 끌다가 전쟁 가까이 가면 그 연도에 붙어요.
- **연도 자**: 큰 막대 위의 눈금자예요. 좌우로 밀면 1년씩, 세게 튕기면 여러 해를 지나가요. 그 시기의 전쟁이 막대로 보이고, 누르면 전쟁 정보가 열려요. 근처에 전쟁이 없으면 양 끝에 가장 가까운 전쟁으로 가는 버튼이 생겨요.
- **월 단위로 펼친 해**: 기록된 날짜가 4개 이상인 해(1592년, 1950년 등)는 연도 자가 1~12월로 펼쳐져서 한 달씩 움직여요. 금빛 바탕이 펼쳐진 해예요.
- 키보드: ←/→ 1년, Shift+←/→ 10년, 연도 자에 초점이 있을 때 PageUp/PageDown 10년, Home/End 처음·끝.

## 한국사 보기 도구

- **한눈에** (왼쪽 위 카드): 지도 가운데 나라를 기준으로 보여 줘요. 한반도가 가운데면 그해의 왕·전쟁·사건·나라 밖 관계·집권 세력, 다른 나라가 가운데면 그 나라와 관련된 전쟁과 한국과의 관계만 보여 줘요. 휴대폰에서는 접힌 한 줄로 시작해요.
- **한국사 연표**: 교과서의 사건과 전쟁을 시대·분류(정치·외교·전쟁·사회·경제·문화·민족운동·민주화·통일)별로 모아요. 분류는 위의 고르기 상자로 바꾸고, '교과서 연표만'을 켜면 비상 교과서의 연표(부록 연표와 단원 첫머리 연표)에 나오는 사건만 보여요. 열면 지금 연도 줄로 바로 내려가요.
- **강과 도읍**: 한강·대동강·낙동강·금강 같은 한반도의 큰 강과 그해 나라들의 도읍(한성·한양, 평양, 금성 등)을 지도에 표시해요. 도읍이 어느 강가에 있었는지 볼 수 있어요. 지도 설정의 '강과 호수'로 강을 끄고 켤 수 있어요.
- **국제 정세**: 그해 한국과 이어진 나라들을 지도 위 선으로 이어요(동맹·사대·교류·사절 길·조약·대립). 평소에는 지도가 복잡하지 않게 감춰 두고 이 창을 열 때만 그려요. 나당 동맹, 남북 세력 대 동서 세력, 냉전 진영 같은 세력 구도도 같이 보여 줘요.
- **세력 흐름**: 고려 지배 세력, 조선의 사림과 붕당(동인·서인·남인·북인·노론·소론·시파·벽파), 개항기 정치 세력, 민족 운동의 갈래, 광복 뒤 정치 세력이 갈라지고 합쳐진 흐름을 그림으로 보여 줘요.

## 한국사 지도 화면 (11단계)

맨 위 **세계 | 한국사** 단추로 바꿔요. 지도가 한반도(고구려·발해 시기는 만주까지)에 맞춰지고, 다른 나라는 흐려지며, 국제 관계선은 꺼져요.

- **지방 행정 구역**: 통일 신라 9주 5소경(685~935), 고려 5도 양계·3경·8목(1018~1391)은 중심지 점과 이름으로, 조선 8도(1413~1895)·13도(1896~1945)는 오늘날 시·도 경계를 합친 대략적인 경계로 보여 줘요. 감영은 옮긴 해(충청 1602 공주, 경상 1601 대구)를 따라요.
- **문화유산**: 용어 사전 가운데 위치가 있는 탑·불상·고분·성 등을 노란 점으로 보여 줘요(만든 해부터).
- **지도** (교과서 지도 44개): 비상 교과서 지도를 바탕으로 미래엔 교과서 지도를 합쳐 옮겼어요. 도별 색칠(대동법), 지점(농민 봉기·의병), 이동 길(통신사·연행사·발해 건국 세력), 구역(고조선 문화 범위·발해 최대 영역)을 연도에 따라 보여 주고, '단계별로 보기'와 범례 끄고 켜기가 돼요.
- **제도** (통치 체제 그림 19개): 고조선 8조법부터 대한민국 임시 정부까지. 교과서 조직도의 구조를 따르고, 교과서가 따로 강조한 기구(예: 조선 3사, 고려 도병마사·식목도감)는 노란 테두리, 교과서 밖 내용은 '심화'로 표시해요.
- **용어** (용어 사전 364개): 두 교과서 찾아보기 용어 가운데 사건·나라·왕·전쟁 이름으로 찾을 수 없던 제도·인물·문화유산·개념을 모았어요. 검색창에서도 찾을 수 있어요.
- **한양**: 도성 성곽·4대문·궁궐·종묘·사직·육조 거리·운종가와 근현대 사건 장소. 연도에 따라 불탐·중건·이름 바뀜(경운궁 → 덕수궁)·철거가 반영돼요.
- **붕당**: 동인(영남)·서인(경기·충청)의 지역 기반, 학통의 중심 서원, 동인·서인 이름이 생긴 한양의 집, 예송·환국 같은 전환점(물러난 세력 → 들어온 세력).
- 주소에 `m=k`(한국사 화면), `th=주제id`, `v=hanyang|bungdang|inst:id|term:이름`이 붙어서 지금 보는 화면을 그대로 공유할 수 있어요.
- 한국사 화면에서는 연도 막대·지도 경계선·이름·전투 점·검색 결과에 우리나라와 관련된 것만 나와요(12단계).

## 자세한 설명 (12단계)

- 사건 527개·한국사 전쟁 44개·용어 364개마다 짧은 설명 아래에 **자세한 설명**(배경 → 전개 → 결과·의의, 헷갈리기 쉬운 점)이 2~4문장 붙어요. 전쟁은 정보 창의 '전쟁의 흐름과 의의'에 나와요.
- 데이터에서는 사건·용어·전쟁 YAML 의 `x` 필드예요. 화면용 JSON 에서는 사건·전쟁은 `dx`(사건의 `x` 는 경도라서), 용어는 `x` 로 나가요.
- 두 교과서 본문을 바탕으로 쓰고, 교과서 밖 내용은 한국민족문화대백과사전에서 확인한 것만 넣었어요. 쓴 작업자와 다른 검수자가 다시 맞춰 봤어요(`docs/review/12단계.md`).

## 질문으로 찾기 (12단계 추가)

- 검색창에 "12목에 지방관을 보낸 왕은?"처럼 질문을 쓰면 **예상되는 답변**(답 1개 + '또는' 2개까지)을 보여 줘요. 답 아래에 근거 문장(찾은 낱말에 형광펜)과 근거 글 이름이 나오고, 누르면 그 글이 열려요.
- AI 가 아니라 앱에 들어 있는 설명 글(사건·용어·전쟁의 짧은 설명과 자세한 설명, 왕 목록)에서 질문 낱말이 많이 겹치는 것을 고르는 방식이에요. 서버·API 키·요금이 필요 없고, 앱에 없는 내용은 답하지 않아요.
- 만드는 방법: 조사·어미를 떼고(마련하고 → 마련), 같은 뜻의 말도 함께 찾고(마련 ↔ 정비, 보낸 ↔ 파견), 드문 낱말일수록 점수를 크게, 질문 낱말을 많이 담은 글일수록 크게 줘요. '왕은?'으로 물으면 근거 글에 나온 왕 이름(그 왕이 다스린 해와 맞는 것만)을 모아 왕으로 답하고, '대통령은?'이면 대통령으로 답해요. 질문에 '고려'·'조선 후기' 같은 시대 이름이 있으면 그 시기 글을 앞으로 올려요.
- 코드는 `web/app.js` 의 '질문으로 찾기' 부분이에요.

## 화면 움직임 (12단계)

- 정보 창은 옆(휴대폰은 아래)에서 미끄러져 들어오고 나가요. 세계·한국사 단추는 색 바탕이 옆으로 움직여요. 기기에서 '동작 줄이기'를 켜면 움직임 없이 바로 바뀌어요.
- 검색 결과에서 연 창에는 '‹ 검색 결과로 돌아가기' 단추가 생겨요. 검색 칸을 누르면 최근에 연 것 8개가 나와요(이 기기 브라우저에만 저장).
- 아래 도구 단추가 연도 막대 폭을 넘으면 작게 줄이고, 그래도 넘치면 두 줄로 놓아요.

## 전투 순서 보기

- 지도 위 전투 점 안의 숫자는 그 전쟁 안에서 날짜 순서예요(전쟁 정보 창 목록의 번호와 같아요).
- 전쟁 정보 창의 **전투 순서대로 보기**: 전투를 날짜 순서대로 하나씩 보여 줘요. 아래 카드에서 이전·다음, 자동 넘기기, 번호 눌러 건너뛰기가 돼요. 아직 안 일어난 전투는 흐리게, 지금 전투는 금색 테두리로 보여요. 진격로와 달리 전투끼리 선으로 잇지 않아요(서로 다른 군대·전선이라 한 길처럼 보이면 틀린 정보가 되니까요).
- **진격로 재생**: 군대가 움직인 길을 날짜에 맞춰 그려요. 0.25배~4배 속도, 일시정지·이어 보기, 막대로 날짜 옮기기, 길마다 끄고 켜기가 돼요. 1·2·3차 침입처럼 따로 일어난 전쟁은 진격로도 따로 나뉘어 있어요.
- 진격로 위 지명은 출발·도착한 곳과 전투가 있었던 곳에만 붙여요(지나간 곳은 점만). 바다 싸움은 우리 수군과 상대 수군의 길을 같이 그려요(임진왜란·정유재란, 백강 전투, 청일·러일 전쟁 등).
- **재생**: 몇 년씩 건너뛰며 재생해도 전투·사건이 있었던 해는 건너뛰지 않고, 날짜(펼친 해는 달) 순서대로 보여 준 뒤 넘어가요. 배속 단추로 빠르기를 바꿔요.
- 한국사 날짜는 1895년까지 음력, 1896년 1월 1일(양력 채택)부터 양력이에요. 세계사는 양력이에요.

## 깃허브에 올리고 사이트 열기

1. GitHub 에서 새 저장소(public) 만들기, 이름은 `history-map` 추천
2. 이 폴더 내용을 그대로 올리기
3. 저장소 **Settings → Pages** 에서 둘 중 하나로 설정
   - **GitHub Actions** (추천): `.github/workflows/pages.yml` 이 `web/` 폴더만 배포해요. 주소는 `https://<아이디>.github.io/history-map/`
   - **Deploy from a branch** (`main`, `/ (root)`): 맨 바깥의 `index.html` 이 `web/` 로 자동 이동시켜 줘요. 주소는 같고, 열리면 `.../history-map/web/` 로 바뀌어요
4. (선택) Actions 탭 → '데이터 다시 만들기' → Run workflow 를 누르면 위키데이터 한국어 이름까지 넣어서 데이터를 새로 만들어요

> 웹에서 폴더를 끌어다 올리면 `.github`, `.nojekyll` 처럼 점(.)으로 시작하는 폴더·파일이 빠질 수 있어요.
> 그러면 Actions 방식이 안 돌아가니까, 이때는 'Deploy from a branch' 를 쓰거나 `git push` 로 올려 주세요.

## 역사 내용 기준

- 한국사: 중학교 역사② (비상교육, 2020) 본문·지도·부록 연표를 기준으로 하고, 날짜·세부 내용은 한국민족문화대백과사전, 우리역사넷(국사편찬위원회)으로 확인
- 원본 데이터와 기준이 다르면 `data/patches/` 에 근거와 함께 수정 내용을 기록하고, 검수 후에 적용
- 학설이 갈리는 부분은 지도에 "학설 차이"로 표시
- 독도는 대한민국 영토로 표기, 바다 이름은 동해로 표기
